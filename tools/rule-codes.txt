# The registry of syntax rule codes: one row per GLECMA_Rule, `number<TAB>enumerator<TAB>name`, where the
# name is what glecma_rule_name returns. A host may store and compare the numbers and the names, so a row is
# never removed, renumbered or renamed, and a new code is appended with the next number. tools/check-rule-codes.py
# fails when the enumeration, the name table and this file disagree, or when a row that is already
# committed has changed or gone.
